# M6 to UAT Transition Blueprint

## 1. M6 Sign-off Criteria
- SEO: meta/OG/JSON-LD, canonical, sitemap/robots, indexing, Lighthouse SEO≥90, CWV targets.
- Regression: all routes pass; cross-browser/device; no broken images/overflow; build+lint status logged.

## 2. UAT Persona Execution Plan
- Product Owner: business logic, core paths, acceptance criteria.
- Prospective Learners: usability, onboarding, navigation, accessibility.

## 3. Zero-Blocker Bug SLA
- Blocker: auth bypass, data loss, crash, critical flow broken. Triage ≤1h, fix ≤4h, verify, escalate.

## 4. Milestone Tracking Table
| Deliverable | Owner |
|---|---|
| M6 audit sign-off | QA Lead |
| UAT onboarding | Scrum Master |
| Blocker triage | Dev Lead |
| Final sign-off Oct25 | PO |
